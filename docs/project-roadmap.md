# 《老板鱼来了》项目路线图

## 双线策略

### Godot Mainline

Godot 4.x 大屏 2D 像素版是当前主线。玩家操控猫咪在办公室鱼塘场景移动、互动、钓鱼、完成摸鱼任务并收集办公室梗鱼。新功能默认在 `godot/` 内设计和实现。

### Electron Legacy

Electron 小窗口版冻结为 Legacy 原型。旧代码、素材和 localStorage 存档逻辑继续保留，必要时可以修复严重问题，但不再默认扩展玩法，也不再继续投入 Canvas 贴图优化。任何 Legacy 修改都必须由任务明确指定并进行旧存档与模块回归。

两条路线不共享运行时代码。Godot 可以参考旧版主题、鱼类名称、文案、数值经验和玩法结论，但不迁移旧 JavaScript。

## 美术与素材路线

- Gemini / FrameRonin 素材可以作为主题、构图和气氛参考。
- Godot 正式美术必须统一像素网格、基础分辨率、调色板、轮廓宽度、动画帧规则、透明边缘和 Nearest 导入设置。
- 不批量迁入 Electron 旧图，不提交失败稿、未使用大图或临时文件。
- v0.1 优先使用可替换的简单色块、tile-like 布局和小型占位资源验证玩法。

## 长期禁止范围

- 不引入 GodotMaker。
- 不做后端、账号、数据库、联网、排行榜或云存档。
- 不删除 Electron Legacy。
- 不把旧 JavaScript 代码翻译或平移为 GDScript。
- 不在缺少验证证据时声明里程碑完成。
