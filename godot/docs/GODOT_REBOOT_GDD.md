# 《老板鱼来了》Godot Reboot GDD（v0.1）

## 产品定位与主线状态

Godot 重启线是《老板鱼来了》的当前主线，是面向 Windows 的大屏 2D 像素单机游戏。玩家操控猫咪在办公室鱼塘场景移动、互动和钓鱼，完成摸鱼任务，收集带有办公室与打工梗的鱼，并在后续应对老板巡查压力事件。

Electron 小窗口版冻结为 Legacy 原型并继续保留。Godot 版不是旧 JavaScript 代码迁移，而是从运行时、场景、交互和内容系统重新实现。

## 核心玩法循环

1. 猫咪在办公室场景中移动，寻找鱼塘、任务板和其他互动点。
2. 玩家在鱼塘进行钓鱼，获得办公室梗鱼与金币。
3. 捕获结果推进今日小委托、图鉴收集和后续商店成长。
4. 老板压力事件在后续版本改变可用时间、移动路线或互动风险。
5. 玩家返回探索和钓鱼，形成短局、可重复的办公室摸鱼循环。

## 场景、角色与互动点

- 主场景：大屏 16:9 办公室，包含工位区、通道、办公室鱼塘和 HUD。
- 玩家角色：可操控猫咪，使用 `CharacterBody2D` 负责移动与场景碰撞。
- FishingSpot：鱼塘边的 `Area2D` 互动点，负责进入范围提示与钓鱼请求。
- 后续互动点：任务板、图鉴柜、商店终端和老板巡查相关区域，按版本独立加入。
- HUD：显示金币、交互提示、钓鱼结果和后续事件状态，不承载底层业务规则。

## v0.1 最小闭环

1. 玩家用 WASD 或方向键移动猫咪。
2. 猫咪靠近鱼塘左侧 FishingSpot 后，HUD 显示 E 键提示。
3. 玩家按 E，固定钓到 `moyu_goldfish`。
4. HUD 显示鱼名、金币奖励和累计金币。
5. 玩家可以继续移动和再次互动。

## 场景与视觉原则

- 逻辑分辨率：1152 × 648（16:9），窗口建议 1280 × 720 或更高等比例尺寸。
- 纹理过滤：Nearest；视觉资产按像素网格设计，避免缩放模糊。
- v0.1 使用色块、简单几何形和小型猫咪占位图构成办公室、工位、走道与鱼塘。
- 不使用整张 AI 背景图铺满场景。后续正式场景应采用 TileMapLayer、可复用道具与独立角色精灵。
- Gemini / FrameRonin 素材只能作为参考；正式资源必须重新统一像素网格、调色板、轮廓、动画帧和透明边缘规范。

## 核心主题

- 《老板鱼来了》与办公室摸鱼。
- 猫咪、办公室鱼塘、老板压力、打工鱼梗和金币。
- 图鉴、今日任务、老板巡查与商店只作为后续方向，本版本不实现。

## v0.1 系统边界

- 角色：单一猫咪，只有八方向移动和碰撞。
- 互动：单一 `Area2D` FishingSpot，使用 E 键。
- 钓鱼：立即结算，无等待条、抛竿状态机或复杂动画。
- 鱼类：数据中仅有摸鱼金鱼和工牌鲤鱼；当前钓点固定产出摸鱼金鱼。
- 经济：金币仅保存在本次运行内，不写入磁盘。
- 平台：Godot 4.x，优先 Windows 桌面导出；本版本不提供导出预设。
- 验收：没有 Godot 导入、运行、人工观察和 Git 证据时，运行结果必须标记“未验证”。

## 技术与产品禁区

- 不引入 GodotMaker。
- 不做后端、账号、数据库、联网或排行榜。
- 不读取或复用 Electron localStorage。
- 不迁移 Electron JavaScript。
- 不把任务、图鉴、商店、存档等业务系统全部塞入主场景。

## 后续候选方向（不属于 v0.1）

图鉴、摸鱼任务、老板压力事件、更多办公室梗鱼、音效、正式像素角色动画、存档和 Windows 导出可以按独立里程碑推进。每项需要单独定义边界和验收证据。
