# 《老板鱼来了》

《老板鱼来了》是一款放置在 Windows 桌面角落的钓鱼小挂件。

当前版本为 **v0.1 早期测试版本**，主要用于验证基础钓鱼体验，功能和画面仍较简单。

## 当前功能

- 420×260 固定小窗口
- Canvas 鱼塘画面
- 自动等待鱼上钩
- 上钩后点击收竿
- 10 种办公室主题鱼
- 钓鱼获得金币
- 使用 localStorage 保存本地进度
- 简单鱼类图鉴
- 商店
- 两个升级：上钩速度、鱼价加成
- 报表模式
- 重置存档

## 当前暂不包含

- 联网功能
- 排行榜
- Steam 成就
- 云存档
- 宠物系统
- 地牢系统
- 鱼竿系统
- 鱼饵系统
- 宝箱系统
- 音效系统
- 托盘隐藏
- 全局快捷键
- 窗口置顶
- 打包安装器

## 运行方式

需要先安装 Node.js 和 npm。

```bash
npm install
npm start
```

运行后会打开一个 420×260 的 Electron 游戏窗口。
