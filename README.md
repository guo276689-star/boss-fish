# 《老板鱼来了》

《老板鱼来了》是一款放置在 Windows 桌面角落的办公室主题钓鱼小挂件。

当前开发分支为 **v0.3-progression-pack**。该需求包仍在开发中，不能视为完整稳定版本。`main` 当前已合并到 v0.2.5。

## 当前功能

- 420×260 Electron 小窗口和可拖动迷你圆形模式
- Canvas 鱼塘与静态像素美术
- 自动等待鱼上钩、点击鱼漂收竿
- 20 种办公室主题鱼、稀有鱼提示和猫猫反应
- 金币、钓鱼统计与 localStorage 本地存档
- 图鉴、商店、今日小委托和报表伪装模式
- Web Audio API 轻音效，默认关闭，用户手动开启后播放
- 新手提示、委托文案、稀有提示文案和报表文案打磨
- v0.3 开发分支内已有：摸鱼等级与称号、图鉴详情、8 个本地徽章、商店当前/下一级效果说明

## 当前禁止范围

- 不做后端、账号、联网、数据库或云存档
- 不做排行榜或 Steam 成就
- 不做复杂宠物养成、地牢或合成
- 不做托盘或全局快捷键
- 不做复杂动画系统
- 不假设项目当前存在服务器或后端

## 开发与验收规则

从 v0.3 起允许“小里程碑分支”：一个大版本使用一个分支，可包含 3～6 个同主题小需求。每个需求建议单独 commit，并且必须单独列验收结果；高风险功能仍使用独立分支。

没有运行证据不得说完成，没有截图或日志不得说 UI 正常，没有 Git commit 不得说已存档，没有手动测试不得说测试通过。无法确认的内容必须标注“未验证”。

## 运行方式

需要先安装 Node.js 和 npm。

```bash
npm install
npm start
```

运行后会打开一个 420×260 的 Electron 游戏窗口。
